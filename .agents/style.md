# Style

Writing rules for everything produced for this project.

## Language

- Communication with the user: Russian.
- Code identifiers, file names, commit messages, repo docs: English.
- Console output of the tool: English keys, short labels.

## Punctuation (Russian text)

- Em dash `-` with spaces around it: `это - пример`.
- Quotes: `«ёлочки»`, nested `„лапки“`.
- Ellipsis: `…`, not three dots.
- Space between number and unit: `5 с`, `30 мс`.

## Tone

- Short answers, no filler, no polite preambles.
- Answer the question first, explain after.
- Do not restate what was done unless asked.

## Code

- No comments unless explicitly requested.
- Minimal diffs, match surrounding style.
- Never print secrets, keys, tokens, or proxy credentials.

## Commits

- Imperative subject line, lowercase, no trailing period, English only.
